# 🧠 AI Resume Builder – Java Full-Stack Web Application

AI Resume Builder is a **Java full-stack web application** that allows users to generate professional resumes dynamically based on their input. The project is built using **Spring Boot** and follows the **Model–View–Controller (MVC)** architecture to ensure clean separation of concerns and scalability.

This application demonstrates core concepts of **Java web development**, server-side rendering, and structured backend design, making it suitable for academic projects, portfolios, and MS Computer Science applications.

---

## 🚀 Features

- User-friendly web interface for resume input
- Dynamic resume generation based on user details
- MVC-based architecture
- Server-side rendering using Thymeleaf
- Clean and maintainable project structure
